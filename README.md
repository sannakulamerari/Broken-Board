# Broken Board – AI Narrative Simulation

Broken Board is an AI-guided, web-based narrative simulation designed to demonstrate how everyday systemic inefficiencies and corruption affect ordinary citizens.

Instead of using random gameplay, the project uses predefined, representative scenarios to help users *experience* the cumulative impact of corruption across infrastructure, education, healthcare, justice, and taxation.

## 🌐 Live Website
👉 https://merychess.my.canva.site/broken-board-ai-narrative-simulation

## 🧠 How AI Was Used
- AI-assisted ideation to frame the problem statement
- AI-generated narrative scenarios representing systemic failures
- AI-generated explanations connecting events to real-world systems
- AI-assisted impact analysis and final summary

## 🎯 Purpose
The goal of this project is to shift corruption from an abstract concept into a lived experience, helping users understand how small, repeated inefficiencies compound over time.

## 🛠 Tools Used
- Canva (design, interaction, and web publishing)
- AI tools for content generation and narrative design
